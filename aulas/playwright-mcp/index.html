Aula 2 · 20 min

Playwright MCP no Claude Code/Codex: o snapshot de acessibilidade na prática

O Playwright MCP dá um navegador ao seu agente de código. Ele não manda captura de tela: manda o snapshot de acessibilidade, com uma referência (ref) em cada controle, e o agente age por essas refs. Nesta aula um script faz exatamente as chamadas que o agente faria, sem modelo, e depois você liga o servidor ao Claude Code ou ao Codex.

Começar a aula

Nesta aula você vai

  1. 1O snapshot com refs (e13, e15, e18)
  2. 2As chamadas: navigate, snapshot, type, select, click, wait_for
  3. 3O erro comum: tirar o snapshot antes de a página terminar
  4. 4Ligar ao Claude Code (.mcp.json) e ao Codex (config.toml)

Objetivo: fazer pelo Playwright MCP o que o agente faz: ler o snapshot, achar o controle pela ref e agir, e ligar o servidor ao seu agente.

Clique em cada bloco.

Depois de agir, um snapshot novo
Clique em cada bloco do diagrama para ver o que ele faz.

A ref vale para aquele snapshot. Mudou a página, tire outro.

02 · O que o agente recebe e o que ele faz

Lendo a saída do ensaio.

1. As ferramentas

O servidor expõe 25 ferramentas de navegador (browser_navigate, browser_snapshot, browser_click, browser_type, browser_select_option, browser_wait_for, browser_console_messages…). O agente vê todas na lista e escolhe.

A documentação do projeto hoje também recomenda um caminho por CLI e skills para agentes de código; o kit usa as ferramentas por MCP, que é o que o Claude Code e o Codex leem.

2. Refs, não coordenadas

No ensaio, o script achou textbox "Seu nome" = e13, combobox "Serviço" = e15 e button "Ver horários" = e18 e agiu por elas. Nada de pixel.

É por isso que o HTML do curso 0 importa: o rótulo vira nome, e o nome é como o agente acha a ref.

3. Esperar a prova

Os horários chegam 1,5 s depois do clique. Com browser_wait_for esperando o texto "horários livres para", o snapshot vem completo. Sem esperar, vem "Carregando horários…" e zero horários.

Espere pelo texto que prova o resultado, não por um número de segundos.

Quem paga o erroUm agente que tira o snapshot cedo demais responde "não há horários" com toda a confiança. A aula 7 volta a esse caso.

03 · O ensaio: as chamadas do agente, sem modelo

O ver-como-agente.mjs liga o Playwright MCP por stdio, como o Claude Code faria, e faz a tarefa "ver os horários de Revisão completa".

Terminal · fazer a tarefa pelo Playwright MCP
cd ~/projetos/formacao-webmcp-navegador-v72/kit
node ver-como-agente.mjs; echo "saída: $?"
Terminal · o mesmo, sem esperar a lista
cd ~/projetos/formacao-webmcp-navegador-v72/kit
node ver-como-agente.mjs --sem-esperar; echo "saída: $?"

O configurar.mjs escreve kit/.mcp.json (Claude Code, escopo de projeto) e imprime o trecho do Codex (na captura, ~ abrevia o caminho; o script imprime o caminho absoluto, que é o que o Codex precisa), que você cola em ~/.codex/config.toml se quiser. Servidor de projeto fica "Pending approval" até você abrir o claude dentro de kit/ e aprovar; depois, o /mcp mostra o servidor conectado (esse passo não foi capturado).

05 · Prática

O ensaio, o seu site e o seu agente. Cada exercício tem um "pronto quando".

E1 · As sete chamadas

10 min

Rode o ensaio e depois a versão sem esperar. Para cada linha com →, diga em uma frase o que o agente sabia naquele momento.

Pronto quando: node ver-como-agente.mjs → 2 (08:00, 13:00) em 7 chamadas e saída: 0; com --sem-esperar → 0 (nenhum) e saída: 1.

E2 · O snapshot do seu site

10 min

Rode o bloco de leitura com o endereço de um site seu. Abra a mesma página no navegador e ache três controles na saída pelo nome.

Pronto quando: node ver-como-agente.mjs com o endereço do seu site → snapshot: N linhas · M elementos com ref e saída: 0.

E3 · O servidor no seu agente

10 min

Rode o configurar.mjs. No Claude Code, abra o claude dentro de kit/ e aprove o servidor do projeto. No Codex, cole o trecho impresso no config.toml.

Pronto quando: claude mcp get playwright → Scope: Project config e, depois de aprovar, Status: ✓ Connected; no Codex, o servidor aparece na lista do /mcp.
