Clase 2 · 20 min

Playwright MCP en Claude Code/Codex: el snapshot de accesibilidad en la práctica

Playwright MCP le da un navegador a tu agente de código. No envía una captura de pantalla: envía el snapshot de accesibilidad, con una referencia (ref) en cada control, y el agente actúa por esas refs. En esta clase un script hace exactamente las llamadas que haría el agente, sin modelo, y después conectas el servidor a Claude Code o a Codex.

Comenzar la lección

En esta lección vas a

  1. 1El snapshot con refs (e13, e15, e18)
  2. 2Las llamadas: navigate, snapshot, type, select, click, wait_for
  3. 3El error común: tomar el snapshot antes de que la página termine
  4. 4Conectar con Claude Code (.mcp.json) y con Codex (config.toml)

Objetivo: hacer con Playwright MCP lo que hace el agente: leer el snapshot, encontrar el control por la ref y actuar, y conectar el servidor a tu agente.

02 · Lo que el agente recibe y lo que hace

Leyendo la salida del ensayo.

1. Las herramientas

El servidor expone 25 herramientas de navegador (browser_navigate, browser_snapshot, browser_click, browser_type, browser_select_option, browser_wait_for, browser_console_messages…). El agente las ve todas en la lista y elige.

La documentación del proyecto hoy también recomienda un camino por CLI y skills para agentes de código; el kit usa las herramientas por MCP, que es lo que leen Claude Code y Codex.

2. Refs, no coordenadas

En el ensayo, el script encontró textbox "Seu nome" = e13, combobox "Serviço" = e15 y button "Ver horários" = e18 y actuó por ellas. Nada de píxeles.

Por eso importa el HTML del curso 0: la etiqueta se vuelve nombre, y el nombre es como el agente encuentra la ref.

3. Esperar la prueba

Los horarios llegan 1,5 s después del clic. Con browser_wait_for esperando el texto "horários livres para", el snapshot viene completo. Si no esperas, viene "Carregando horários…" y cero horarios.

Espera el texto que prueba el resultado, no un número de segundos.

Quién paga el errorUn agente que toma el snapshot demasiado pronto responde "no hay horarios" con toda la confianza. La clase 7 vuelve a este caso.

03 · El ensayo: las llamadas del agente, sin modelo

05 · Práctica

El ensayo, tu sitio y tu agente. Cada ejercicio tiene un "listo cuando".

E1 · Las siete llamadas

10 min

Ejecuta el ensayo y después la versión sin esperar. Para cada línea con →, di en una frase qué sabía el agente en ese momento.

Listo cuando: node ver-como-agente.mjs → 2 (08:00, 13:00) em 7 chamadas y saída: 0; con --sem-esperar → 0 (nenhum) y saída: 1.

E2 · El snapshot de tu sitio

10 min

Ejecuta el bloque de lectura con la dirección de un sitio tuyo. Abre la misma página en el navegador y encuentra tres controles en la salida por su nombre.

Listo cuando: node ver-como-agente.mjs con la dirección de tu sitio → snapshot: N linhas · M elementos com ref y saída: 0.

E3 · El servidor en tu agente

10 min

Ejecuta configurar.mjs. En Claude Code, abre claude dentro de kit/ y aprueba el servidor del proyecto. En Codex, pega el fragmento impreso en config.toml.

Listo cuando: claude mcp get playwright → Scope: Project config y, después de aprobar, Status: ✓ Connected; en Codex, el servidor aparece en la lista de /mcp.
