Clase 1 · 15 min

El mapa de oct/2026: computer use, extensiones, navegadores con agente y herramientas de dev

Agente de navegador se convirtió en varias cosas distintas: un modelo que mira la pantalla, una extensión en tu Chrome, un navegador entero con agente dentro y herramientas que le dan un navegador a Claude Code o a Codex. En esta lección separas las cuatro familias, lees el estado de cada una con fecha y dejas listo el kit del curso.

Comenzar la lección

  3. 3El kit: Playwright MCP y Chrome DevTools MCP con versión fijada

02 · Cómo leer el estado de un agente

Tres preguntas antes de creer.

1. ¿Quién lo dijo?

Un post del fabricante, la documentación o el repositorio oficial valen como hecho. Una nota de prensa o un agregador valen como "reportado por".

Ejemplo: el post de Anthropic del 24/11/2025 es fuente primaria; la fecha de lanzamiento de Atlas, aquí, solo vino de la cobertura.

2. ¿Cuándo?

Escribe la fecha junto al estado: "beta en el plan Max el 24/11/2025", y no "está en beta". En seis meses la frase sin fecha se vuelve mentira.

La versión de un paquete también es estado: el kit fija @playwright/mcp 0.0.83 (28/09/2026) y chrome-devtools-mcp 1.10.1 (23/09/2026).

3. ¿Corre dónde?

La extensión y el navegador con agente corren en la cuenta de alguien y gastan suscripción. Las herramientas de dev corren en local, contra 127.0.0.1, sin ningún modelo si quieres.

Por eso el curso ensaya todo con ellas y deja el agente real para un paso opcional.

Regla del cursoAgente de navegador solo contra la página del kit o contra un sitio tuyo. Nada de login real, compras ni formularios de terceros.

03 · El kit listo en dos comandos

Instala las versiones fijadas y revisa las piezas. El versoes.mjs no llama a la red ni a ningún modelo.

Terminal · instalar el kit
[ -d ~/projetos/formacao-webmcp-navegador-v72 ] || git clone -q https://github.com/inematds/formacao-webmcp-navegador-v72 ~/projetos/formacao-webmcp-navegador-v72
cd ~/projetos/formacao-webmcp-navegador-v72/kit
npm ci --no-audit --no-fund && npx playwright install chromium; echo "saída: $?"
Terminal · revisar las piezas
cd ~/projetos/formacao-webmcp-navegador-v72/kit
node versoes.mjs; echo "saída: $?"

El npm ci instala exactamente lo que está en el package-lock.json. La primera vez, el npx playwright install chromium descarga el Chromium de Playwright (unos cientos de MB); en las siguientes, no imprime nada.

04 · Práctica

El kit en tu máquina y tu mapa.

E1 · Kit listo

10 min

Ejecuta los dos bloques. Si falta una pieza, su línea empieza con "falta:" y dice qué hacer.

Listo cuando: node versoes.mjs → kit pronto: 4 de 4 peças obrigatórias y saída: 0.

E2 · Tu mapa

10 min

Crea mapa-agentes.md con tres agentes de navegador que tú o tus clientes usan, una línea por agente: familia | agente | estado | fuente | fecha. Un estado sin fuente pasa a "reportado por".

Listo cuando: grep -c "|" mapa-agentes.md → 3 o más, y cada línea tiene una fecha.
